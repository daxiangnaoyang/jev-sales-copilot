# Jev 销售副驾

macOS 桌面应用，用于整理客户沟通、生成销售跟进策略、制作产品介绍素材，并记录沟通复盘。

## 功能

- 客户管理：手动新增、选择客户，保存客户资料与沟通记录。
- 销售副驾：读取粘贴或导入的对话，生成结构化判断、下一步策略和候选回复。
- 产品素材：在 Agent 对话框中一次提交产品文字和多张图片，自动整理到可编辑事实卡；结果可一键确认，再生成推荐语、朋友圈短文、电商图解结构草稿和 15 秒视频分镜。可选接入视频模型 API，从分镜直接创建视频任务。
- 沟通复盘：回看每轮对话、判断、策略和风险，并标记复盘状态。
- 微信辅助：微信切到前台后自动锚定当前对话并显示逐条 OCR 预览；用户核对会话标题、客户归属和消息方向后才能载入草稿。会话列表需手动导入（当前可见区域最多 10 个候选）；候选回复可回填到微信输入框。

## 开发

技术栈：React、TypeScript、Vite、Tauri 2、Rust。macOS 通过 Core Graphics 枚举微信窗口，以系统 `screencapture` 截取指定窗口，再用 Vision 本机 OCR；辅助功能用于确认焦点窗口和回填输入框。

需要 Node.js、npm、Rust 工具链及 macOS Command Line Tools。开发和浏览器演示：

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:1420`。浏览器模式可新增/切换客户、载入虚构测试客户与对话，粘贴聊天文本，或由用户逐次选择共享一个聊天窗口并在本机 OCR。屏幕 OCR 可读取企业微信或其他聊天 App 当前可见的一帧；用户需框选名单/消息区、检查识别文字与发言方，再导入草稿或最多 10 个客户候选。截图不上传、不保存；首次使用会联网加载并缓存 OCR 模块及中文识别模型。网页客户策略分析仍是本地演示；产品资料可在模型配置后由浏览器直接请求 Agent，前提是服务允许浏览器跨域访问，API Key 只保留在当前运行内存。视频任务也可从网页直接提交；若浏览器跨域策略拦截，可在 macOS 桌面 App 中操作。网页不会自动切换或滚动外部 App。

检查前端并运行 Rust 测试：

```bash
npm run build
cd src-tauri
cargo fmt --check
cargo test
```

构建 macOS App：

```bash
npm run tauri -- build --bundles app
```

生成文件位于 `src-tauri/target/release/bundle/macos/Jev 销售副驾.app`。

本仓库默认使用临时签名（`signingIdentity: "-"`），用于本机开发构建。macOS 会以应用的 designated requirement 关联隐私权限；ad-hoc 签名的 requirement 绑定到具体代码版本，因此重打包后录屏授权可能失效。需要反复实测微信 OCR 时，先在登录钥匙串安装稳定的 Apple Development 签名身份，并在首次运行时授权。用 `security find-identity -v -p codesigning` 查看身份，再通过 `APPLE_SIGNING_IDENTITY="<钥匙串中的证书名称>" npm run tauri -- build --bundles app` 构建；Tauri 支持该环境变量覆盖当前 ad-hoc 配置。不要把证书或私钥提交到仓库。详见 [Tauri macOS 签名说明](https://v2.tauri.app/distribute/sign/macos/)与 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

## 使用

### 模型与服务

从左侧栏底部打开“模型与服务配置”。

- **客户判断：Bocha Jev**。固定使用 `bocha-jev-v1`，接口为 `https://jev.bocha.cn/v1/systemone`。输入 Bocha Jev Client API Key，或在启动环境提供 `BOCHA_JEV_API_KEY`（兼容 `BOCHA_SEARCH_API_KEY`）。
- **Agent 策略模型**：可选本机 Demo、本机 Ollama、OpenRouter 免费路由、OpenAI API 或自定义 OpenAI-compatible 服务。按所选服务填写模型 ID；先测试连接可读取模型目录。
- **视频生成模型**：可保持未接入，或选择火山方舟 Seedance 2.5。填写 API Key 并测试模型目录后，在视频分镜下点击“按分镜生成 15 秒视频”；每次创建任务前会再次提示可能产生费用。
- Agent 与视频模型的服务选择、接口和模型 ID 会保存在本机；API Key 只在当前运行期间保留，不保存。Bocha Jev 和云端 Agent 的客户对话授权分别设置，重启后需重新授权。
- 测试连接只读取服务模型目录，不提交客户对话或创建视频任务。云服务额度与费用按对应服务商账户和当前政策为准。

### 客户沟通

1. 打开微信并切到前台；应用自动定位当前对话。客户列表可手动新增、切换和移除；如需导入名称，手动点“导入会话列表”，仅处理当前可见的最多 10 个候选。
2. 当前对话会显示窗口锚点、识别标题、逐条消息、发言方向和 OCR 置信度。核对客户归属并点“确认对象并载入”后，文本才会进入草稿。标题 OCR 置信度只表示文字识别把握，不代表客户身份已验证；方向不确定的文字不会作为客户原话发送给判断模型。检查草稿后，再选择 Agent 服务并分别授权需要接收本轮对话的服务。
3. 点击“生成策略”，查看客户判断、下一步动作和候选回复。
4. 复制回复，或使用回填功能放入微信输入框；检查无误后由用户手动发送。

微信截图和 OCR 在本机处理。微信成为前台时应用定位当前对话并刷新预览；会话列表导入由用户手动触发，只处理当前可见名称，最多导入 10 个。群聊过滤依赖 OCR 识别名称中的群聊标记，不能据此保证所有导入项都是单聊，使用前请核对。读取微信窗口需要 macOS“屏幕录制”权限；回填输入框需要“辅助功能”权限。应用不会自动载入识别草稿、自动分析或发送微信消息。

Bocha Jev 收到的对话最多 6 条且总长不超过 300 字符；Agent 请求最多接收 12,000 字符。启用云端服务前请检查设置页授权说明。

### 浏览器验证客户与聊天

在客户沟通页点击“读取当前聊天”或“读取可见名单”，然后在浏览器共享选择器中手动选企业微信或其他聊天窗口。每次只读取一帧；聊天模式请把会话标题与消息区一起框选，标题 OCR 只有唯一精确匹配时才自动选择客户。未匹配时不会沿用上次客户；核对名称后可新建客户，或手动选择已有客户。之后可逐行修正文字和客户/销售发言方。日期/时间行默认忽略，低置信度行默认未确认。聊天文本只进入客户草稿，点击“本地演示分析”才会写入本机消息与复盘记录；名单候选最多添加 10 位，需逐项核对，群聊过滤只排除 OCR 明确出现群聊标记的项目。网页不能自动滚动、切换聊天 App 或读取未显示内容；此通用屏幕路径不等于企业微信原生适配或官方会话存档 API。

屏幕画面在浏览器内存中处理，不上传也不保存；首次 OCR 会从 Tesseract.js 分发源加载并缓存识别运行时与简体中文/英文模型。若浏览器不支持屏幕共享或加载模型失败，可继续使用虚构样例或手动粘贴。网页客户策略分析仍使用本地演示；只有在用户主动提交产品整理或视频生成时，浏览器才会把相应文字/图片发给已配置的 Agent 或视频 API。跨域被服务商拒绝时，界面会提示改用桌面 App。

也可点击“载入网页测试客户与对话”新增并切换到虚构测试客户，显示三条样例消息；它不会替换其他客户，也不代表真实聊天已识别。手动粘贴可逐轮标注 `客户：…`、`我：…`，独立日期/时间行会忽略。未标注粘贴文本视为用户手动提供的客户原话。

### 产品素材与沟通复盘

在“产品素材”中像聊天一样粘贴产品介绍，并可在同一轮添加最多 8 张产品图片。选择 Agent 模型后，桌面 App 通过 Tauri 命令、网页通过浏览器请求所选 OpenAI-compatible 服务；网页服务需允许 CORS。只有本机 Demo 模式会按原文预整理且不识别图片。Agent 回填产品名称、品类、人群、场景及卖点到可编辑事实卡；事实默认待核对，点击“一键确认整理结果”会确认有文字/图片证据的字段，证据不足的项目仍保留待核实。识别到不同产品名称时，替换当前事实卡和草稿前会请用户确认。

整理后的图片在本机保存，每个项目最多保留 12 张，可单张移除。之后生成推荐语、朋友圈短文、电商图解结构草稿和 15 秒视频脚本。在“模型与服务配置”选择 Seedance 2.5 并填入 API Key 后，可从视频脚本提交 15 秒任务；创建任务前需要明确点击确认，可能产生服务费用。成片以远端链接预览，链接有效期 24 小时，需及时打开或保存；实际成片必须人工检查，任务 API 的连通测试不会创建视频。图解目前是内容结构草稿，不是已渲染图片。在“沟通复盘”中查看已生成的判断和策略并标记复盘。

客户资料、聊天记录、产品素材图片、产品信息和复盘记录保存在本机应用数据中。

## 项目结构

- `src/App.tsx`：应用页面与交互流程。
- `src/persistence.ts`：本地资料和服务偏好存储。
- `src/product.ts`、`src/strategy.ts`：产品内容与本地策略构造。
- `src/browser-agent.ts`：网页模式连接 Agent、模型目录检查与多模态产品资料整理。
- `src/video-provider.ts`、`src/video-storyboard.ts`：视频 API 任务提交/查询与分镜提示词构建。
- `src/browser-conversation.ts`：浏览器粘贴聊天的日期/时间过滤、说话方解析和客户记录导入。
- `src/BrowserScreenReader.tsx`、`src/browser-screen-capture.ts`：用户选择共享源后的单帧截取、选区 OCR 与逐条校对。
- `src/browser-screen-reader-utils.ts`：OCR 行角色建议、日期过滤与聊天草稿格式化。
- `src-tauri/src/lib.rs`：Tauri 命令注册。
- `src-tauri/src/macos_wechat.rs`：macOS 微信窗口、OCR、回填及 Agent/视频服务请求。
- `docs/ARCHITECTURE.md`：当前代码结构和调用流程。
- `docs/WECHAT-AGENT-JEV.md`：微信与模型服务使用及开发说明。
